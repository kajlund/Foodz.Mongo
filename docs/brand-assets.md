# Mise brand assets

The approved Mise asset package is installed under `apps/web/public`:

- `brand/mise-horizontal.svg` — primary wordmark for light backgrounds
- `brand/mise-mark.svg` — standalone cooking-pot and rosemary mark
- `brand/mise-one-color.svg` — single-color mark and wordmark
- `brand/mise-dark.svg` — light wordmark for dark backgrounds
- `favicon.svg` and `favicon.ico` — browser favicons
- `icons/mise-icon-{16,32,48,192,512}.png` — raster application icons

The visual identity reference is stored at `docs/design/mise-identity.png`.

## Brand direction

Mise means “everything in its place.” The identity combines an editorial cookbook wordmark with a simple cooking-pot and rosemary mark. Interfaces should feel calm, organized, warm, and practical.

## Colors

- Forest green: `#263F2D`
- Herb green: `#557746`
- Warm ivory: `#F6F2E9`
- Paper white: `#FFFDF8`
- Saffron: `#ECA51B`
- Terracotta: `#AA5A32`

Use the SVG files whenever possible. Raster icons are intended for browser, operating-system, and installable-app surfaces.
